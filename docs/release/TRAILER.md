# Trailer: shot list

Ninety seconds, cut from the running game. `pnpm playthrough` photographs one
year end to end (`playthrough/`); record the same seed with the browser's own
screen recorder at 1440×900 for motion. No voice-over: the game's own text
carries it. Music optional and quiet.

| Time | Shot | On screen |
|---|---|---|
| 0–6 s | Black. Text: "You have just been made head of cyber security." | — |
| 6–14 s | The first message arriving in the inbox | "The CEO meeting starts in 23 minutes" |
| 14–24 s | The first decision dialog, an option chosen | "Where do you start?" |
| 24–34 s | The organisation map opening, dashed boxes; one turning solid | Key: Checked / Taken on trust |
| 34–44 s | The risk list; an enquiry commissioned; a leader chosen | "Commission the work" |
| 44–52 s | An executive card; the board paper's agenda with ratings | "Pick what the committee sees" |
| 52–64 s | Skip ahead; the year strip filling; a quiet stretch | "Q2 closes in 63 days" |
| 64–76 s | The incident bar arriving; the response decisions | "Incident active" |
| 76–86 s | The annual review masthead and headline | The year's verdict, in its own words |
| 86–90 s | Title, and the address | "CISO: First Year" |

Use seed `class-25` in CISO mode for a summer ransomware incident (see
`docs/educator/FACILITATOR.md`); check with `pnpm cohort` that it still
arrives before recording.
